# Optional — Investigative OSINT

Everything in this folder is investigation-style technique, not standard technical pentest workflow. Use only when engagement scope explicitly includes a social-engineering, phishing-simulation, or physical/red-team component. For a standard web/API pentest, skip this folder entirely after the priority-technical pass and go straight to `02-reconnaissance/`.

Each subfolder below is kept as a reference — detailed enough to use if a relevant engagement comes up, but intentionally not part of the default workflow.
